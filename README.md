# 365 Days With You ❤️ — Galang × Azulia

Website anniversary 1 tahun, Next.js App Router + TypeScript + Tailwind CSS + Framer Motion + Lucide.

## Jalankan
1. `npm install`
2. Masukkan foto ke `public/images/`:
   - couple.jpg
   - memory1.jpg ... memory8.jpg
3. Masukkan lagu ke `public/music/our-song.mp3`
4. `npm run dev`
5. Buka `http://localhost:3000`

Jika foto/lagu belum ada, foto otomatis memakai `placeholder.svg`. Audio tidak dipaksa autoplay oleh browser: pemutaran dimulai setelah tombol opening ditekan.

## Edit data
Titik awal counter ada di `components/LoveCounter.tsx`.
Isi timeline ada di `components/JourneyTimeline.tsx`.
Isi kartu alasan ada di `components/LoveReasons.tsx`.
Isi surat ada di `components/LoveLetter.tsx`.
